- Added a real body for The Listener: tall and eyeless, with long reaching arms and ear-slits that glow when it clicks
- Added twitchy head movement: The Listener's head snaps toward sounds, and it hunches and reaches when it hunts you
- Added The Listener's rasping breath, so you can hear it before you see it
- Added a shriek when The Listener starts hunting you (Survivor and Nightmare only)
- Added close-call dread: the screen edges darken red and your flashlight flickers as it gets near (Survivor and Nightmare only)
- Added new poses for The Replacement: it's never standing the same way when you look back (Explorer only gets head tilts)
