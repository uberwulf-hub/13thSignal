## New
- Added a CATCH SCARE switch to the main menu, so older players can turn on the full jump scare in Explorer themselves. It asks a times-table question first, so little ones can't switch it on by accident, and it stays on only until the game closes
- Added two Parent Settings for that switch: lock it, or make the full scare permanent in Explorer
- Made the Android app's signing key permanent, so updates always install over the old copy without uninstalling

## Fixed
- Centred the number pad (Parent PIN, elevator code, and the new question) on the screen
