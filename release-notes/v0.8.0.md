## New
- Made every game's puzzles different:
  - Sector 1: a new breaker order each game, with new clues on the maintenance note. The painted colours swap places too
  - Sector 3: the receivers move, so every relay lab needs a new answer. A solver checks each layout first, so every lab can always be solved
  - Sector 5: the pressure plates move. Each one always stays far enough from its door that you still need your copy
  - Sector 6: the power board's labels are missing, and each switch runs a different circuit every game. Flip one to find out, and the board writes it in
  - Key items (keycard, note, fuse, jammers, shutter button, elevator key) start in a different spot in their room each game
