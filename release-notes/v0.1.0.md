## New
- Added Sector 1: Intake, the first playable part of the facility
- Added three modes: Explorer (no jump scares), Survivor and Nightmare
- Added the Parent Lock: the game always starts in Explorer, and Survivor and Nightmare need a Parent PIN
- Added The Listener, a blind monster that hunts by sound and learns your habits
- Added The Replacement, a mannequin that only moves when you can't see it
- Added the breaker puzzle, the security keycard and the elevator colour code (a new code every game)
- Added 3 hidden signal fragments, one behind a vent you have to crouch through
- Added controller support
