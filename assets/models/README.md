# Models

Put a human mannequin model here as `mannequin.glb` and the game uses it for the
Replacement (and the scare glimpses) instead of the built-in shape mannequin.
It's scaled to 1.85 m and given the glossy plastic look automatically.

Only add models you're allowed to redistribute (CC0, or a license that allows
use in a distributed game), and add a line for it to `saucestore.json` credits
and `licenses/`.
